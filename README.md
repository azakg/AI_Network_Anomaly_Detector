# AI Network Anomaly Detector

AI-assisted network anomaly detection platform for analyzing network logs and generating analyst-friendly explanations.

## Goals
- Ingest network logs
- Detect suspicious patterns
- Explain anomalies using AI
- Provide a dashboard for review

## Stack
- FastAPI
- PostgreSQL
- Docker Compose
- Python
